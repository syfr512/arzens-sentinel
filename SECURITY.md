# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability. Send a private report to the project maintainer or organization security contact with a concise description, affected component, reproduction using a sanitized local fixture where possible, and impact assessment. Do not include target credentials, raw customer evidence, or live report links.

## Supported use

Arzens Sentinel is designed for authorized, bounded Safe Passive assessments. The product must not be used to scan targets without permission, pursue exploitation, or collect authentication material. See `docs/RESPONSIBLE_USE.md` and `docs/LIVE_TESTING_RUNBOOK.md` for operational boundaries.
